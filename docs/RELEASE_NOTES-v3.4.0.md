# 萤 v3.4.0

## 完全免费与开源

- 取消赞助解锁高级功能，全部功能（整活样式、节日皮肤、壁纸取色、每日一句、神秘模式、本地字体导入、文字描边等）对所有用户免费开放。
- 移除密钥验证、解锁状态、Cloudflare Worker 与相关文档；赞助页保留为纯支持入口，输入任意内容会播放礼花彩蛋，不产生任何权益。
- 赞助入口从设置一级页移到「更新与关于」；关于区仓库指向 `github.com/jiuxina/ying`。
- 在线字体资产迁入开源仓库 `ying` 的 main 分支。

## 更新与下载

- 更新检测迁移到 `github.com/jiuxina/ying` Releases，按设备 ABI 自动选择对应 APK。
- 发现新版本后先看版本说明，再进入下载源选择：GitHub 直连 + 三个镜像（`ghfast.top`、`gh-proxy.com`、`ghproxy.net`）并发测速，自动默认选最快，也可手动切换。
- 支持应用内下载：显示进度与取消按钮，下载完成后自动拉起系统安装器；未开启「安装未知应用」权限时先引导授权。

## 首页交互

- 顶栏（头像 + 设置按钮）只在「日子」Tab 显示，「日历」Tab 不再显示。
- 「日子」下拉刷新时事件卡片整体下滑，筛选栏保持固定。
- 无横向交互的区域可以左右滑动切换 Tab；事件卡片横滑仍执行卡片操作；日历月/年视图网格内横滑分别翻月、翻年。

## 说明

- 旧版本已写入的赞助偏好键保留但不读取，不影响数据与小部件配置。
- 更新下载使用 `ying/installer` 原生通道与 FileProvider，Android 清单新增 `REQUEST_INSTALL_PACKAGES`。
