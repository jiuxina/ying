# 第 5 阶段详细计划：趣味主题包

> 状态：已实现，`flutter analyze`、Dart 回归测试与 Android `testDebugUnitTest` 通过
> （2026-08-09），对应 [update-plan.md](update-plan.md) 阶段 5。

## 摘要

第 5 阶段在不新增独立数据模型的前提下，把六套趣味主题接入阶段 1 的主题架构：
神秘信封、时间胶囊、复古 CRT、霓虹灯牌、像素血条与镜像整活。设置页样式列表新增六项，
应用内预览与 Android 小部件同步渲染；协议升级到 v6（向后兼容），旧配置缺样式字段时回退「卡片」。

## 关键改动

### 1. 神秘信封

- 新增 `envelope` 样式，单事件小部件默认显示信封封面，点击封面触发 provider 广播，
  按 `widgetId` 翻转 `widget_envelope_open_$widgetId` 状态并刷新该实例。
- 信封封面为程序绘制位图（信封、封舌、火漆与「点击查看事件」提示），展开后隐藏封面、
  露出正常倒计时内容；列表模式只使用信封主题背景，不叠加封面。
- 每个小部件实例独立记忆开合状态，互不干扰。

### 2. 时间胶囊

- 新增 `capsule` 样式，背景为胶囊 + 表盘视觉。
- 当 `dayDelta == 0` 时切换为恭喜卡片：标题「恭喜！事件名」、主数字「🎉」、单位「就是今天」，
  强调色覆盖临近高亮色；其余日期保持胶囊倒计时。

### 3. 复古 CRT

- 新增 `crt` 样式，深绿屏幕底色 + 横向扫描线 + 亮绿描边。
- 主数字与正文使用荧光绿文字色，保持对比度。

### 4. 霓虹灯牌

- 新增 `neonSign` 样式，暗色底 + 多层霓虹描边背景。
- 数字区使用独立 `widget_days_neon` 视图，叠加 XML 白色光晕并把文字色设为当前强调色，
  模拟灯牌发光效果，不依赖运行时字体下载。

### 5. 像素血条

- 新增 `pixelHealth` 样式，暗色像素网格背景 + 像素化数字字体。
- 中号单事件卡片在数字旁绘制 12 格像素血条，按「创建日到目标日」进度填充；
  小号卡片不显示血条，避免拥挤。

### 6. 镜像整活

- 新增 `mirror` 样式，背景为镜像斜纹渐变纹理，内容整体轻微旋转（-2.5°）。
- 数字与标题保持正向可读，镜像效果由背景承担，兼顾 200% 字号与对比度要求。

## 测试计划

- Dart 单测：v6 协议版本、六套新样式按名称往返、未知样式回退 card。
- Widget 测试：六套主题预览渲染无异常；时间胶囊在目标日显示恭喜文案；
  神秘信封预览显示封面。
- Android 单测：六套新样式名称解析；单事件布局包含 `widget_days_neon`、
  `widget_health_bar` 与 `widget_envelope_cover`；provider 源码包含信封揭示处理。
- 验证命令：`flutter analyze`、按文件拆分 Dart 回归、`gradlew -p android :app:testDebugUnitTest`。

## 假设与注意事项

- 趣味主题本轮以 Android AppWidget 与应用内预览为准；iOS WidgetKit 的样式扩展留待后续评估。
- 神秘信封不新增 Dart 数据字段，开合状态只在 `HomeWidgetPreferences` 按 widgetId 保存。
- 时间胶囊判定复用 `WidgetEvent.daysFromToday()` 的本地日期，不重复实现时区逻辑。
- 所有新样式沿用旧配置回退：`parseWidgetStyle` / `AppSettings.fromMap` 对未知值返回 `card`。
- RemoteViews 不支持动画层与自定义 View，信封开合用状态位切换，霓虹发光用独立 TextView
  的 XML 阴影，像素血条用程序绘制位图。
