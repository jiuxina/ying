# 萤 v3.2.0

## 新增

- 小部件字体切换升级：数字字体与文字字体独立选择。
- 在线字体库：DSEG7、Orbitron、霞鹜文楷 Lite、得意黑可一键下载并应用，字体按需存放到本地，不增加安装包体积。
- 本地字体导入：赞助解锁后可导入 TTF / OTF，选择数字、文字或两者用途并立即应用。
- 应用内小部件预览同步显示自定义数字 / 文字字体。

## 说明

- 内置字体预设与在线字体库免费开放；本地字体导入为赞助功能。
- 小部件协议升级到 v9，旧小部件无需重新配置，缺少新字段时保持原显示。
- Android 桌面小部件通过位图渲染自定义字体，缺失字体文件时自动回退系统字体。
