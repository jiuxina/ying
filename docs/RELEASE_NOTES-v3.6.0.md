# 萤 v3.6.0

## 全新轮盘选择器

- 新增自研中文轮盘式日期选择弹窗，替代系统日期 / 时间选择器：年 / 月 / 日三列联动，顶部实时预览目标日期、中文星期与倒计天数。
- 关闭「全天事件」后可同时选择时间，年 / 月 / 日 / 时 / 分五列轮盘，预览实时同步。

## 新增 / 编辑日子页面改版

- 快捷日期一步直达：今天、明天、一周后、一个月后、今年年底，或走轮盘自定义。
- 分类标签带上图标（生活 / 工作 / 学习 / 纪念日 / 旅行 / 其他），更易区分。
- 保存与取消按钮固定在底部操作栏，长表单滚动时始终可见。

## 提醒设置升级

- 提醒选项「选中即添加」，并新增「自定义提醒时间」：数量 + 单位（分钟 / 小时 / 天）双轮盘，自由组合提前量。
- 提醒选项弹窗在矮屏上可滚动，修复内容溢出问题。

## 其他

- 应用版本号升至 3.6.0（build 10）。
