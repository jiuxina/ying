# 萤 · 赞助制解锁方案

> 目标：核心功能完全免费，只把不常用的趣味 / 装饰功能作为"赞助解锁"；收款走爱发电，解锁走卡密；不走应用商店、不做订阅、不限制核心功能，最大限度保护免费用户与口碑。

## 1. 模式定位

- 赞助制不是售卖：所有界面与文案使用"赞助支持"，不用"购买 / 收费 / 订阅"。
- 免费用户无功能损失：不限制事件数量、提醒条数、小部件实例，也不限制数据相关功能。
- 解锁范围只覆盖低频、纯趣味、纯外观的功能，属于"喜欢再支持，不支持也不影响使用"。
- 适合个人开发者：不需要企业资质、不需要商店账号与抽成，渠道成本最低。

## 2. 为什么推荐"爱发电收款 + 卡密解锁"

- App 不需要接入爱发电 SDK，也不会把开发者 token 塞进客户端。
- 卡密支持离线验签，断网也能解锁，延续"本地优先、无账号"的定位。
- 分发走 GitHub Releases 直发 APK，项目已有 GitHub 应用内更新检测，天然配套。
- 爱发电只负责收款和展示，卡密独立于收款渠道；以后换渠道不影响已有用户。

备选方案（第一版不建议）：

- 爱发电开放 API 查询赞助状态：需要服务端持有开发者凭证，否则凭证会泄露。
- 自动发卡平台：省人工，但引入第三方依赖，且需要研究其发货规则。

## 3. 功能分层

### 3.1 免费版（保留全部常用功能）

- 事件创建、编辑、删除、搜索、分类、排序、置顶、连续撤销。
- 倒计时 / 正计时、日历总览、每年重复。
- 每事件最多 5 条提醒、通知快捷操作、提醒诊断。
- 深色 / 浅色 / 跟随系统主题。
- 桌面小部件：总览与单事件、基础常用样式（卡片 / 贴纸 / 玻璃 / 极简等）、基础颜色与字号、列表模式、快速完成、数据同步。
- 数据导出与导入。

### 3.2 赞助解锁（只解锁不常用功能）

| 功能 | 说明 |
| --- | --- |
| 整活样式 | 神秘信封、时间胶囊、复古 CRT、霓虹灯牌、像素血条、镜像整活 |
| 节日皮肤 | 节日自动换肤 |
| 壁纸取色 | 从壁纸提取小部件配色 |
| 每日一句 | 小部件每日文案 |
| 神秘模式 | 小部件隐藏关键信息 |
| 数字字体 | 数字字体切换 |
| 文字描边 | 文字描边效果 |
| 相册背景 | 可选：若担心争议可留在免费版 |

> 原则：凡是"很多人会日常用到的"，一律免费；只有"整活、小众、纯外观"的才放进赞助解锁。最终清单由你确认，可随时调整。

### 3.3 赞助档位建议

- 建议单档：一次性赞助 ¥12 起，获得长期赞助解锁，无需订阅。
- 也可以两档：¥6 尝鲜（解锁部分整活样式）、¥18 完整（全部赞助功能），档位和价格最终由你定。
- 爱发电页面文案统一写"赞助支持，解锁全部赞助功能"，避免承诺"永久权益"这类强承诺。

## 4. 卡密技术方案

### 4.1 离线签名卡密（推荐）

- 格式：`YING-XXXXXX-XXXXXX-XXXXXX`。
- 生成：开发者用私钥对卡密内容签名（建议 Ed25519），App 内嵌公钥离线验签。
- 优点：无服务器、无网络依赖、隐私友好、防随意篡改卡密格式。
- 缺点：公钥内嵌且源码开源，可被反编译或自编译绕过；对低客单赞助场景可以接受。
- 密钥管理：私钥不提交仓库，保存在本机环境变量或加密文件中；生成工具独立于 App。
- 卡密内容建议：包含签名、有效期起点、适用的版本范围，防止旧版无限复用。

### 4.2 防共享

- 离线模式无法做设备绑定，第一版不做绑定，文档明示"卡密请勿公开分享"。
- 若卡密被大规模分享，再增加轻量服务端兑换（Cloudflare Worker 或自建接口），不影响现有架构。

## 5. 爱发电接入方式

- 方式 A（推荐，零后端）：爱发电页面设置档位说明，赞助后通过私信或自动回复发放卡密；App 只提供爱发电主页入口。
- 方式 B（自动发卡）：接入自动发货 / 第三方发卡平台，订单成功后自动发卡密。
- 方式 C（App 内查询赞助状态）：调用爱发电 API，需要后端保存凭证，第一版不做。

App 内只需要一个"赞助支持"页面：赞助说明、爱发电入口、卡密输入框、当前解锁状态。

## 6. 技术改动清单

### 6.1 新增

```text
lib/
  models/unlock_state.dart              # 解锁状态：unlocked、activatedAt、keyHash、签名
  services/unlock_service.dart          # 卡密输入、离线验签、持久化、状态读取
  state/unlock_controller.dart          # Riverpod StateNotifier，启动加载并广播状态
  ui/sponsor_page.dart                  # 赞助说明 + 爱发电入口 + 卡密输入 + 状态
  ui/unlock_badge.dart                  # 赞助徽标
tools/
  generate_card_keys.dart               # 开发者本地生成卡密，私钥不提交
```

- `pubspec.yaml` 新增签名验签依赖（如 `ed25519_edwards` 或等价实现），可选新增 `url_launcher` 用于打开爱发电链接。

### 6.2 修改

- `lib/services/storage_service.dart`：新增 `sponsor_unlocked`、`sponsor_key_hash`、`sponsor_activated_at` 键。
- `lib/services/widget_service.dart`：同步写入 `widget_sponsor_unlocked`。
- `lib/ui/settings_page.dart`：分类菜单顶部新增"赞助支持"卡片。
- `lib/ui/settings_category_page.dart`：赞助项（整活样式、节日皮肤、壁纸取色等）未解锁时显示锁标记，点击提示赞助。
- Android `DaymarkWidgetProvider.kt`、`DaymarkDetailWidgetProvider.kt` 与 iOS `DaymarkWidget.swift`：读取赞助标记，未解锁时隐藏整活样式。

### 6.3 与买断制方案的区别

- 不限制事件数量、不限制提醒条数、不限制小部件实例。
- 不做数据功能墙，不出现"请升级后继续使用"的核心阻塞。
- 不接应用商店支付，不依赖 Play Billing / StoreKit。

## 7. 实施步骤

### Phase 0：决策（1 天）

1. 确认赞助解锁功能清单与免费 / 赞助边界。
2. 确认赞助档位、价格、爱发电页面文案。
3. 确认卡密格式与有效期策略。

### Phase 1：卡密底座（2–3 天）

1. 实现 `generate_card_keys.dart` 与私钥管理说明。
2. 实现 `UnlockService` 验签、持久化与 `UnlockController`。
3. 实现赞助页、设置入口、解锁状态展示。
4. 补充 Dart 单元测试与页面 Widget 测试。

### Phase 2：功能锁（2–3 天）

1. 设置页与小部件样式项加锁。
2. `WidgetService` 同步赞助标记，Android / iOS 原生小部件降级。
3. 小部件回归测试。

### Phase 3：分发与发布（2–3 天）

1. 构建并发布 APK 到 GitHub Releases。
2. 配置爱发电页面与自动 / 手动发卡流程。
3. 更新 README、商店说明（如有）与更新日志。

### Phase 4：上线后（持续）

1. 收集卡密使用与分享情况。
2. 修复验签、恢复、版本升级相关问题。
3. 若卡密被滥用，再评估在线兑换与设备绑定。

## 8. 测试与验收

- Dart 单元测试：有效 / 无效 / 过期 / 格式错误卡密、状态持久化。
- Flutter Widget 测试：赞助页各状态、加锁项点击行为、解锁后解锁。
- Android 原生测试：未解锁时整活样式回退。
- 模拟器验证：`adb install` 安装 APK，输入测试卡密，重启后状态保持，小部件正常降级 / 解锁。
- 发布前跑完整 `flutter test` 与现有 Android 单测。

## 9. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 卡密被公开分享 | 收入损失 | 第一版接受；后续加在线兑换与设备绑定 |
| 开源源码可自编译绕过 | 收入损失 | 接受；赞助制本质是"支持作者"，不是强付费 |
| 用户误以为功能被阉割 | 差评、口碑受损 | 文案强调核心功能完全免费，仅趣味功能可选赞助 |
| 爱发电规则或收款变化 | 发卡流程中断 | 卡密独立于爱发电，可切换其他收款渠道 |
| 版本升级后旧卡密失效 | 用户不满 | 卡密签名带版本范围，升级前公告并预留过渡期 |

- 赞助档位与价格（建议单档 ¥12 起，长期解锁）。
- 爱发电页面链接与档位文案。
- 是否第一版就做卡密防共享（建议不做）。
