# 萤 v3.3.0

## 新增

- 首页左上角改为圆形头像，可在“外观与显示”中从相册选择、更换或恢复默认头像。
- 头像默认不再带主题色底色，并支持带透明通道的 PNG 图片，透明区域直接透出页面背景。
- 首页设置按钮固定在页面顶栏，不再悬浮遮挡内容；“萤”标题移除，待完成计数移到设置按钮下方，默认头像使用软件图标并略低于设置按钮。
- 小部件元素字号支持 0.5–2.0 连续滑块调节，新增 100–900 字重滑块（0 表示跟随默认）。
- 小部件全局字号滑块范围扩展到 0.5–2.0。
- 小部件新增整体内容边距调节，范围 4–40dp，默认 16dp。
- 相册背景支持选图时自由矩形裁切，保存后可重新裁切，并可调整亮度与高斯模糊。

## 说明

- 新功能全部免费开放。
- 小部件渲染协议升级到 v10，旧配置缺省回退默认值，无需重新配置。
- Android 动态字重通过位图通道渲染；精确秒与节日徽章使用加粗近似。
- 修复 Android 小部件因 RemoteViews 无法调用 setFakeBoldText 而显示“无法加载微件”的问题；精确秒与节日徽章改用 setFontVariationSettings 实现加粗近似（Android 8+ 生效）。
- 旧版本相册背景缺少源图时，重新裁切会引导重新选择照片。
- iOS WidgetKit 本轮保持原有独立实现。
