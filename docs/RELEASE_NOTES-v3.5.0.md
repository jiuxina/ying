# 萤 v3.5.0

## 小部件样式精简

- 移除霓虹、像素、极简、神秘信封、时间胶囊、复古 CRT、霓虹灯牌、像素血条与镜像整活九套样式，保留卡片、贴纸、照片、玻璃、拍立得五套。
- 旧配置或未知样式值统一回退「卡片」，桌面小部件与预览保持一致。

## 字体库

- 在线字体按钮改为「下载」，下载后不再自动应用。
- 字体库不再提供应用按钮，本地导入也不再自动应用；应用统一在「字体」设置中选择数字 / 文字字体。
- 字体许可以小字显示在下载按钮旁，移除独立许可卡片。
- 下载按钮移到字体卡片右侧。

## 桌面小部件预览

- 设置页小部件预览仅保留小号预览卡片，移除中号预览。

## 其他

- 应用版本号升至 3.5.0（build 9）。
