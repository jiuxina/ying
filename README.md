## 为什么选择萤

- **本地优先**：所有数据只保存在设备上，无账号、无服务端。
- **简单专注**：只做好倒数日这一件事，打开就能用。
- **高度可定制**：头像、主题、桌面小部件样式与内容都可以按你的习惯调整。
- **完全免费开源**：全部功能免费开放，源码公开。
- 如果可以的话，希望能点个 Star 支持一下呢～

## 核心功能

### ⏱️ 倒数日与正计时

- 精确到秒的倒数日 / 正计时，自动识别已过与未到事件。
- 支持每年重复、分类、备注、置顶、搜索、筛选与多种排序。
- 今天、明天、一周后、一个月后、今年年底等快捷日期，随手可用。

### 📋 事件管理

- 创建、编辑、删除与恢复事件，删除和完成都有 6 秒撤销窗口。
- 已完成事件独立折叠，可一键清理。
- 事件卡片支持滑动、长按操作菜单与独立详情页。

### 📅 日历总览

- 月视图、年视图与按月份分组的列表视图。
- 月视图点选日期即可查看当天安排，重复事件按年份自动显示。

### 🔔 提醒

- 每个事件最多 5 条提醒，通知点击直达事件详情。
- 可直接在通知中完成或稍后提醒。

### 📱 桌面小部件

- 总览与单事件专注两种小部件，多套样式可选。
- 支持逐元素颜色、字号、对齐与显隐，壁纸取色、相册背景、节日皮肤等。
- 应用内实时预览，添加与刷新都很方便。

### 🎨 个性化

- 深色、浅色、跟随系统主题。
- 自定义头像、Emoji、单位文案、农历星期、进度环、在线字体与本地字体导入。

### 🔒 本地优先

- 无账号、无服务端，数据只属于你。
- 支持备份导出与导入。

### ⬇️ 应用内更新

- 自动检查新版本，可选择直连或镜像下载源，测速后自动推荐最快的通道。
- 下载完成后直接在应用内完成安装。

## 安装

1. 前往 [Releases](https://github.com/jiuxina/ying/releases) 下载最新 APK。
2. 根据设备架构选择 `arm64-v8a`、`armeabi-v7a` 或 `x86_64`。
3. 安装后按提示授予必要权限，即可开始使用。

> 也可以在 App 的「更新与关于」中自动检查更新，应用会测速并选择最快的下载源，在应用内完成下载与安装。

## 快速上手

1. 点击首页右下角 `+` 新建倒数日，填写标题、日期与分类。
2. 在「日历」Tab 查看月视图、年视图与日程列表。
3. 长按桌面添加小部件，在设置中调整样式与内容。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| 通知权限 | 事件提醒与通知快捷操作 |

| 电池优化 / 自启动（可选） | 让提醒与桌面小部件更稳定 |
